Slot Machine

GitHub branch: html5-ui

State-of-the-art rotor game simulation (Alex Duesel, GPL-3.0)

Game help

Simulation of a commercial slot machine with state machine, bonus scheme, and special rules.

Basics
  • 3 reels × 2 rows, up to 4 paylines depending on mode.
  • Normal spin: 20 Money, start: 2000.
  • Symbols: 7, 1BAR/2BAR/3BAR, JACK, coins 20C–160C.

Controls (HTML5 UI)

  • Left panel — ASCII reels, game log, cheat field + Spin, two option checkboxes (see Interactive mode), automatic batch mode, Restart game.
  • Right panel — SVG reels, counters, risk ladder with four action buttons when a risk game is active.
  • During risk, Spin is disabled; use the ladder buttons instead (same keys as CLI: empty = 50% step, 5 win, 4 accept, 1 lose).
Interactive mode

In interactive play, each spin sends an input line to the engine — like the original CLI -i mode. The two checkboxes below Spin apply only here (not in automatic batch mode). You can change them at any time during interactive play; they take effect on the next spin.

Every spin skips left-reel restart (CLI -i / cheatrun)

Default: on. When enabled, every spin sets cheatrun, even with an empty cheat field — like the legacy CLI -i mode. Main effect: the left reel restart rule is skipped (no re-roll of the left column when neither left cell is a premium symbol). Payout tends to be higher than fair spins. This does not force a fixed reel picture on empty spins; it only changes the restart rule. More wins indirectly mean more risk-ladder entries, but the ladder itself is still played manually with the buttons.

When disabled (Fair spins), an empty spin behaves like automatic batch mode: left reel restart applies; cheatrun is only set if you enter a cheat letter a–p or a debug command.

Cheat letters a–p force fixed reel picture (risk ladder)

Default: on. When enabled, a cheat letter a–p replaces the random draw with a fixed reel picture from the cheat table (get_cheatrun). Many of these pictures are coin wins and therefore start the risk ladder (e.g. code e → three 50c symbols → Risk Left). When disabled, cheat letters still set cheatrun (and still skip left reel restart if the first checkbox is on), but the random reel draw is kept — useful to test without forcing risk-ladder scenarios.

Debug commands (cheat field + Spin)

These work in interactive mode regardless of the checkboxes:

  • SUPER n — add n Super games
  • TURBO n — add n Turbo games
  • EXTRA n — add n Extra points (70% risk wins on steps 6/8/10)
  • JACKS n — add n Jackpot points
  • MONEY n — add n Money

Restart game

Restart game stops the current run (like CLI q), resets counters and state, and starts a fresh interactive session. Usable anytime — also while automatic mode or a risk game is running.

Risk ladder

After certain coin wins you enter a risk game instead of taking the prize immediately. You climb a ladder rung by rung — each successful step credits a higher prize; a failed step ends the risk game and returns to the reel game (unless special fail draws apply at the very top).

Which ladder?

  • Risk Left — triggered by a 50C×3 win (also some Turbo-mode combinations). Ladder of larger left-side prizes up to 150 Turbo games.
  • Risk Right — triggered by 80C×3 or 160C×3 wins. Ladder of right-side prizes up to 140 Turbo games.

Your coin win sets the starting rung (e.g. 50C win → step 2 on Risk Left). The base coin amount is credited when the risk game begins; each successful climb credits the next rung shown on the ladder.

Rung layout (13 steps each)

The panel shows both ladders; only the active side is highlighted. Steps count from 1 (bottom) to 13 (top). Completed rungs are marked done; the current rung pulses.

Risk Left
30C → 50C → 100C → 200C → Draw 300 → 3S → 6S → 12S → 12T → 25T → 50T → 100T → 150T
Risk Right
20C → 40C → 80C → 160C → Draw 200 → 2S → 4S → 8S → 8T → 20T → 40T → 80T → 140T

S = Super games, T = Turbo games, C = Money (cents).

Your four actions

While the ladder border is flashing, use the buttons below it (same keys as the original CLI in parentheses):

  • Continue (50%) — Gamble: 50% chance to move up one rung (credits next prize), 50% chance to lose the risk game and return to reels.
  • Win ↑ (5) — Force a successful step up (test / cheat input).
  • Accept (4) — Stop climbing; take the prize of the current rung and exit to Win. On Risk Right step 11, accepting can also award a Jackpot point (special rule).
  • Lose (1) — Force a failed step (drop out of the risk game).

Outcomes

  • Climb to the top (step 13) — automatic Win with the top prize.
  • Fail before the top — back to reel game. If another winning line was pending from the same spin, that line is evaluated next (Normal / Four-Row modes).
  • Fail at the top — consolation mini-game: Draw Fail 50 (Risk Left) or Draw Fail 40 (Risk Right).
  • Step 5 auto-draw — reaching rung 5 (Draw 300 on Left / Draw 200 on Right) triggers that draw automatically; no button input on that step.

Special rules

  • Extra Point — on steps 6, 8, and 10, the next gamble uses a 70% win chance and jumps two rungs on success.
  • Extra-Plus counters — while active on the matching side, lower rungs also use 70% win chance.
  • Blind mode (-b) — skips the risk ladder entirely; coin wins go straight to Win.
  • Reels stay visible during risk; the spin button is disabled until you return to the reel game.
Automatic mode

Like CLI: -n game count, -b blind, -r total risk, -a accept 40TS, -m macro, -l logging. Macro example: a5[10]1.

Cheat codes a–p

Enter one letter in the cheat field, then press Spin. An empty field gives a random draw (unless the Cheat letters a–p force fixed reel picture checkbox is off and Classic CLI is off — see Interactive mode).

When cheat pictures are enabled (default), each letter forces a fixed reel picture (top row left→right, then bottom row). Letters also set cheatrun, which skips the automatic left-reel restart when neither left symbol is a premium symbol — if Every spin skips left-reel restart is on, that skip applies to every spin anyway.

Effects below apply to the primary win in Normal mode (two horizontal lines). Codes o and p can trigger a second winning line on the bottom row. In Turbo / Four-Row mode, diagonal wins are evaluated as well.

a
Top row 30C×3 → Draw 30 mini-game
b
Top row 20C×3 → Draw 20 mini-game
c
Top row JACK×3 → Jackpot
d
Both rows 50C–80C–30C → no win (test picture)
e
Top row 50C×3 → Risk Left ladder (50C)
f
Top row 160C×3 → Risk Right ladder (160C)
g
Top row 50C–80C–160C → no win (test picture)
h
Top row 50C–80C–JACK → no win (test picture)
i
Top row 50C–80C–3BAR → no win (test picture)
j
Top row JACK×3 → Jackpot (different bottom row than c)
k
Top row 50C–80C–7 → no win (test picture)
l
Top row 50C–80C–7, bottom 50C–80C–30C → no win (test picture)
m
Top row 80C–50C–80C → no win (test picture)
n
Bottom row 160C×3 → Risk Right ladder (160C)
o
Top row 2BAR×3 → Draw 3×BAR; bottom 160C×3 → Risk Right (two wins)
p
Top row 7×3 → Draw triple-7; bottom 160C×3 → Risk Right (two wins)
